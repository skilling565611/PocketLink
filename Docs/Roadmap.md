# PocketMedic Roadmap

## Core Goals

- Lightweight portable PC utility
- Support Control Prime and Arctic Prime
- EXE + Source compatibility
- OneDrive / USB / Local tool support

## Planned Major Systems

- Build / Runtime Baseline
- Machine Profiles
- Installer Management
- System Diagnostics
- Thermal Monitoring
- USB / External Device Detection
- Backup / Recovery
- GitHub Models / AI Integration
- Security / Vault Support

## Future Ideas

- Storage Forecast
- App Update Checker
- Environment Cloner
- Hardware Calibration
- Android Companion App
